# PARI // 001

Bu oddiy romantik landing page emas — mobil qurilmada ochiladigan interaktiv "maxsus fayl" tajribasi.

## Ishga tushirish

npm install
npm run dev

## Ovoz

Brauzerning sun'iy o'zbekcha `speechSynthesis` ovozi ishlatilmaydi.

Haqiqiy ovoz yozuvlaringizni:
public/audio/

papkasiga quyidagi nomlar bilan qo'ying:

intro.mp3
file.mp3
final.mp3

Keyin `src/main.jsx` ichidagi AUDIO_FILES ni moslang.
